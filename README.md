# 光エステ販買マスター Ver.1.0.0

GitHub Pages向けの静的PWAです。

## アップロードするもの
このフォルダの中身を、リポジトリの一番上（root）へそのままアップロードしてください。
- index.html
- manifest.webmanifest
- sw.js
- icon.svg
- nojima_lineup.jpeg

## GitHub Pages
Settings → Pages → Deploy from a branch → main / root を選択。

## 内容
- 縦スクロール中心（iPhone / iPad対応）
- 接客用お悩み別チャート
- メーカー・機種比較
- IPL図解
- 接客フロー
- ホーム画面追加対応
